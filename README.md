# Our Little Home — 背景画像修正版

## 修正内容
- 部屋の背景画像をHTML内に埋め込みました。`assets/rooms` フォルダのアップロード漏れや相対パスの不一致があっても、背景画像を読み込める構成です。
- 部屋背景の暗いオーバーレイを弱め、イラストが見えやすいようにしました。
- PWA用の `manifest.json` と `icon.svg` を追加しました。

## GitHub Pagesへの反映手順
1. ZIPを展開します。
2. GitHubで対象リポジトリを開きます。
3. `index.html`、`manifest.json`、`icon.svg` をリポジトリ直下にアップロードして既存ファイルを置き換えます。
4. Commit changes を押します。
5. 公開URLを開き、Windowsなら Ctrl+F5 で再読み込みします。スマホではページを再読み込みし、まだ古い画面ならブラウザのサイトデータ/キャッシュを消して再度開いてください。

※この修正版では背景画像をHTMLに埋め込んでいるため、背景表示だけなら `assets/` フォルダは必須ではありません。フォルダ内の画像は参考素材として同梱しています。
※既存のローカル保存方式は維持しています。別端末間の同期機能は別途Cloudflare Workers/D1/R2等の実装が必要です。
